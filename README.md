# ⚔️ Path to Ascension

**Path to Ascension** is a 2.5D Metroidvania-style platform-adventure game built with Unity. Players explore mysterious environments, overcome obstacles, solve puzzles, and battle enemies while progressing through challenging levels.

## 🕹️ Features
- 2.5D platforming and exploration
- Character movement, climbing, and double jumping
- Combat and enemy interactions
- Environmental puzzles and obstacles
- Health and stamina systems
- Push-and-pull object interactions
- Keyboard and gamepad support

## 🛠️ Tech Stack
**Unity** • **C#** • **Unity Input System**

## 👨‍💻 Development
Developed as a **group project for the Game Programming course at Cambodia Academy of Digital Technology (CADT) in 2024**.

**My Role:** Game Programmer — responsible for implementing character mechanics and animations, including movement, jumping, climbing, combat, and player interactions.
